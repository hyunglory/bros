## v0.3 운영 지침 변경 내역

- 분야별 작업 단계가 끝날 때와 모델·추론 수준을 변경하기 전에 결정 기록을 남긴다.
- 결정 기록에는 확정 결정, 기각안, 변경 파일, 검증 증거, 미해결 사항, 다음 작업의 범위·금지 변경·완료 조건을 포함한다.
- 다음 모델은 대화에서 이전 추론을 추측하지 않고 `docs/DECISIONS.md`의 최신 승인 결정을 인수한다.
- 기존 결정을 변경할 때는 덮어쓰지 않고 `supersedes` 관계가 있는 새 기록을 추가한다.
- 모든 작업 완료 보고에 `[추천 모델과 추론성능]`을 포함해 다음 작업의 모델·추론 수준과 전환 조건을 안내한다.

평가 표본 수, 성능·복구·보존·경보 수치는 **이번 개정의 초기 운영/검증 목표**다. 기존 실측 결과를 인용한 값이 아니다. 제품군·운영 규모에 따라 변경할 때 근거와 영향 범위를 DECISIONS에 남긴다. 공급자 선정·실데이터 정답 검수·운영 자동승인 활성화는 입력과 평가가 필요하다.

## 문서 정합성 검증

- Task ID: Phase 1 14개 / Phase 2 16개 / Phase 3 14개 / Phase 4 15개 / Phase 5 13개 / Phase 6 13개, 총 85개 유지.
- 기준 업무 테이블: 기존 18개 유지. 새 인증/Outbox 업무 테이블을 암묵적으로 추가하지 않음.
- 검증 범위: 로컬 Markdown 파일 참조, 코드펜스 균형, Task ID 중복/개수, 명시적 Task 선행관계의 참조 및 순환 여부.
- 2026-09-11 검증 결과: Markdown 7개, 로컬 파일 링크 17개 정상, 코드펜스 균형 정상, 85개 Task 중복 없음, 명시적 Task 선행관계 순환 없음, 18개 테이블 유지. Phase Gate 및 서술형 조건은 문서 대조로 별도 검토했다.
- 실제 DB·API·Worker·브라우저·외부 Provider·운영 성능은 아직 검증하지 않았다.
